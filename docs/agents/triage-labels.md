# Triage labels

| Rolle | GitHub-Label | Bedeutung |
| --- | --- | --- |
| needs-triage | needs-triage | Muss bewertet werden |
| needs-info | needs-info | Weitere Angaben fehlen |
| ready-for-agent | ready-for-agent | Ausreichend spezifiziert für einen Agenten |
| ready-for-human | ready-for-human | Menschliche Umsetzung erforderlich |
| wontfix | wontfix | Wird nicht umgesetzt |

Skills verwenden die hier zugeordneten Labels.
Ein Bereitschaftslabel ersetzt keinen Implementierungsauftrag.
